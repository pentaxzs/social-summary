## 배달의민족 을지로체 (BMEuljiro.woff2)
## 배달의민족 한나체 Pro (BMHannaPro.woff2)

- 저작권: ㈜우아한형제들
- 라이선스: SIL Open Font License 1.1
- 전문: https://www.woowahan.com/fonts

배달의민족 폰트는 개인·기업 모두 무료로 사용할 수 있고, 수정·재배포가
허용됩니다. 글꼴 파일 자체를 유료로 판매하는 것만 금지됩니다.

원본은 `.woff` 로 배포되며, 이 저장소에는 용량을 줄이기 위해 `.woff2` 로
변환해 두었습니다 (fontTools, 글리프 변경 없음).

이 페이지에는 우아한형제들에서 제공한 배달의민족 폰트가 적용되어 있습니다.
